# Mathematics
These papers are not serious mathematical literature. I have simply written them out of passion, and to practice using LaTeX and improve my mathematical abilities. All of these papers have been written about discoveries which are not new, but those of which I have discovered independently.

## An Independent Method for Deriving Closed Forms of Homogeneous Second-Order Linear Recurrence Relations with Constant Coefficients
This was my first LaTeX project. It details a method which I independently discovered for deriving closed forms of certain recurrence relations using my knowledge of solving ordinary differential equations. At the end of the paper, it details concise formulas for determining these closed forms, proceeding the derivation of these.

## Investigation of a Family of Polynomial-Exponential Product Functions
I wrote this paper about an interesting family of functions which I found useful for solving non-homogeneous recurrence relations - which I was researching at the time. Though these functions are fairly trivial, this paper is the most technical I have written so far, with a lot of computation. Throughout the paper, I investigate the structure of these functions, finally deriving a closed formula for the structure of this family of functions, which is depicted at the end of the paper.

## Areas of regular n-gons in Euclidean space
This paper follows a very brief derivation of a simple formula used to find the area of any regular n-gon in Euclidean space. Although this formula is simple, I have not seen it before, so I thought it would be interesting to write about. Additionally, I also used this small project as a medium to practice using set theory - which I have only recently studied.
